# El prompt per començar · La IA, la teva aliada

Pàgina temporal del claustre del 17/11/2026 (Institut de Celrà): el prompt guia per muntar un cervell virtual amb Obsidian, amb botons per copiar-lo, desar-lo i obrir-lo a la IA, i els PDF de la presentació.

- `site/`: la web (es genera amb `node build.cjs <carpeta d'icones Tabler>`).
- `caducada/`: el que es publica a partir del 17/11/2026 a les 23:59 (hora de Madrid).
- `.github/workflows/pages.yml`: publica `site/` i, a partir de l'hora de caducitat, publica `caducada/` (la web deixa d'existir). La pàgina també es bloqueja sola al navegador a la mateixa hora.

Després de la caducitat es pot esborrar el repositori.
